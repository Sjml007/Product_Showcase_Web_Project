## Packages
framer-motion | Core requirement for all cinematic and scroll animations
lucide-react | Iconography throughout the application
clsx | Utility for constructing className strings conditionally
tailwind-merge | Utility to merge tailwind classes efficiently

## Notes
- This is a purely static frontend application.
- No backend endpoints are called.
- Custom fonts (Orbitron and Rajdhani) are imported in index.css.
- The theme uses a custom neon green (#7CFF4F) and deep black (#050505) color palette.
- Tailwind config needs to support arbitrary values or standard CSS variables defined in index.css.
